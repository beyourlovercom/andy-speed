## Detached signature contract

This branch adds **development-only release scripts** without changing the runtime plugin source. PHP libsodium implements Ed25519 detached signature; signed metadata must bind the exact package name, SHA-256, semantic version and source commit. The verification key **must be obtained through a separately trusted channel**, not pulled from the signed metadata or an untrusted web response.

Signing and verification are intentionally **fail closed**. Signing requires a dedicated environment variable called `ANDY_SPEED_UPDATE_SIGNING_SECRET` containing a 64-byte secret key encoded as Base64 and a separately approved Base64 public key parameter. The tool rejects a wrong public key, missing ZIP, metadata mismatch or existing signature. The verifier rejects incorrect public key, changed metadata, altered ZIP or filename mismatch.

The scripts do **not** automatically generate, store, export, print or upload a production private key. Never reuse `ANDY_CORE_UPDATE_SIGNING_SECRET`, paste keys in ChatGPT or commit a private key to GitHub. The independent test harness generates and destroys ephemeral keys inside an isolated test process; it requires no production secrets.

For a future authorized release, copy the byte-identical candidate to the canonical name `andy-speed-v0.2.1.zip`, generate matching update-metadata.json with fields `schema_version=1`, `version=0.2.1`, `package=andy-speed-v0.2.1.zip`, `sha256` and `source_commit`. Provision a new Andy Speed public/private identity in approved secret custody, then run the signer and verifier. Only after a trusted detached signature passes verification may the exact files be proposed for release.

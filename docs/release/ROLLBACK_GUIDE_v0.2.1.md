# Andy Speed v0.2.1 — rollback guide

Publishing to GitHub does not install this plugin on a website.

For an independently authorized WordPress install, the administrator may turn on **Emergency OFF** in Tools → Andy Speed and save. The plugin then reverts its CSS changes to the six original theme stylesheets. A site administrator can also deactivate Andy Speed if its settings page is unavailable.

Check the homepage, product pages, Cart, checkout display, currency selector and analytics attribution after any authorized rollback. Andy Speed controls do not revert independently deployed BYL V3 Theme Hero changes. Avoid shared page caching and never modify Stripe, orders or coupons as part of plugin rollback.

WWW and Dev installation, upgrades and live rollback remain separate Owner authorization gates.

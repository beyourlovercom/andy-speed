## Findings

1. PairDoll has two distinct Elementor `slides` widgets: desktop widget `6287346` (autoplay 5,000ms; hidden on mobile), mobile widget `9c0199b` (autoplay 3,000ms; hidden on desktop/tablet). The mobile Lighthouse LCP candidate is a carousel background `Photo-album-banner-correct-size.jpg`, with 6.55–7.55s of element render delay. Carousels may update LCP long after the initial useful paint.
2. LiteSpeed option readback: `litespeed.conf.guest=1`, `litespeed.conf.guest_optm=1`, `litespeed.conf.optm-guest_only=1`. Public HTML issues `guest.vary.php` and can trigger `window.location.reload(true)` for a fresh visitor. Mobile Lighthouse redirect opportunity estimated 3.48–5.89s. It is a diagnostic clue, **not proof** that all real visitors incur that delay.
3. LCP JPEG `Photo-album-banner-correct-size.jpg` ~573KiB; logo `PAIRDOLL-LOGO.png` ~177KiB is displayed around 100 × 50. Lighthouse flags image-delivery savings. Verify optimized equivalents and visual parity before any URL or media metadata switch.
4. TBT is already 0ms and desktop performance 95. Global JS stripping, CSS removal, or a second page cache is unjustified.

## Proposed controlled gates

- **R0 read-only baseline (complete):** preserve independent Lighthouse reports; official services pending.
- **R1 source experiment (this PR):** opt-in `pairdoll_mobile_slider_stability` in Andy Speed v0.3.0-dev, default OFF, exact `pairdoll.com` / `woodmart-child` / homepage / Elementor mobile widget ID. `autoplay` becomes `no` in *rendered HTML*, preserving manually operated controls and desktop widget. No stored Elementor document write and no mobile User-Agent branch or cache variants.
- **R2 isolated guest-mode A/B (not yet run):** compare LiteSpeed Guest Mode ON/OFF with option backup, page-cache purges strictly scoped, fresh guest cookies, and verified WooCommerce cart/checkout/affiliate/currency behavior. Only change LiteSpeed's own settings if a separately backed-up canary demonstrates a measurable, repeatable benefit; Andy Speed must never silently alter third-party cache options.
- **R3 image options (not yet run):** test equivalent WebP/AVIF plus responsive logo with screenshots, LCP accuracy, existing R2-offloaded image mapping and no duplicate downloads. Never silently overwrite originals.
- **R4 validation (not yet run):** at least three comparable independent Lighthouse Mobile/Desktop runs **per option**, three device viewport screenshots, product > cart > checkout (no payment), coupon/country/currency/affiliate attribution and public SEO/structured-data smoke. Obtain **authentic** current PageSpeed Insights Mobile/Desktop and GTmetrix provider report; target 90+ verified for both platforms.
